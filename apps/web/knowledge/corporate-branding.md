# Corporate branding standards

Version: 1.0.0 | Synthetic customer: Contoso Sales Demo

## Project and page naming
Use `SalesPerformance` as the project name. Use short, audience-oriented page names. The primary executive page is `Executive Summary`; a secondary analysis page may be named `Regional Performance`.

## Theme
Use the fictional Sales Demo theme: white background `#FFFFFF`, text `#172B4D`, and primary accent `#005A9C`. Branding must remain readable and must not imply association with a real customer.
